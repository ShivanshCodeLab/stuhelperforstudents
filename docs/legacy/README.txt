STUHELPER STUDENT WORKSPACE

HOW TO RUN
1. Extract this ZIP.
2. Open the StuHelper_Student_Workspace folder.
3. Open index.html in a modern browser (Chrome, Edge or Firefox).

WHAT IS INCLUDED
- Overview dashboard (today panel, deadlines with overdue alerts, subject progress, weekly focus chart, recent activity) and personal workspace
- Library for books, notes, PDFs, links and local file attachments
- Syllabus tracker with subject/chapter progress and priority targets
- Assignment tracking and deadlines
- Productivity desk with timer, tasks, scratchpad, daily goal and habits
- Student toolkit: marks, percentage, timetable, flashcards, exam countdown and quick calculators
- Document utilities and image export tools

DATA & PUBLISHING
Study records are saved in browser localStorage on this device. Library attachments are stored in this browser (3 MB per file limit). Clearing browser data may remove them. A publish request is saved as Pending moderator review. This static ZIP does not include a server, user accounts, admin panel, moderation API or public hosting; therefore it cannot actually publish a resource or perform real moderator approval. Connect a secure backend and admin review workflow before enabling public publishing.

IMAGE FORMATS
Image export includes PNG, JPG, WebP, AVIF (browser-dependent), BMP and SVG wrapper. SVG wrapper embeds the raster image; it is not a vector conversion.


NOTEBOOK UPDATE
- Rich-text formatting now preserves the selected text when toolbar buttons are clicked.
- Added left, center, right and justified paragraph alignment.
- Notes autosave in this browser's local storage on this device.
- Use Export .txt for plain text or Save formatted .html to keep bold, italic, colours,
  highlights, lists and alignment in a portable file.
- To use the app on the web, upload the complete folder to a static host (for example
  GitHub Pages or Netlify). The notebook works in the browser there too.
- Browser local storage is tied to the browser/device and website origin. A static
  website does not automatically sync notes between devices. Cross-device cloud sync
  requires a backend/database and user accounts; it is not included in this static build.
